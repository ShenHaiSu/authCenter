# 02 页面与交互设计

> 前端架构文档 2/2 ｜ 每个页面的元素、交互流程、API 映射、错误处理

## 1. 登录页（login.html）

| 元素 | 说明 |
|------|------|
| 表单 | 用户名（默认提示 admin）、密码（type=password）、登录按钮 |
| 提示区 | 错误信息（"用户名或密码错误"、锁定提示） |
| 附加 | 首次使用提示：初始密码见服务端控制台 / `data/auth.log` |

交互流程：
```
加载 → GET /admin/me → 已登录 → 跳 index.html
提交 → POST /admin/login
      ├─ 成功 → 跳 index.html
      └─ 失败(20101/20102/429) → 表单下方红色提示
```

API：`GET /admin/me`、`POST /admin/login`。错误处理：429 显示"尝试过于频繁，请 15 分钟后再试"。

## 2. 主界面框架（index.html）

布局：左侧导航（仪表盘 / 项目 / 审计日志 / 修改密码 / 使用教程 / 对接文档 / 登出）+ 右侧内容区；顶部显示当前用户名。

```
导航项点击 → showView(id) 切换内容区视图
登出 → POST /admin/logout → 跳 login.html
```

| 视图 id | 对应 JS | 内容 |
|---------|---------|------|
| dashboard | dashboard.js | 统计卡片 + 最近认证事件 |
| projects | projects.js / keys.js | 项目列表与密钥管理 |
| audit | audit.js | 审计日志查询 |
| password | app.js | 修改密码表单 |
| guide | guide.js | 管理员使用教程（静态内容，无 API，见 §10） |
| docs | docs.js | 接入方对接文档 + Markdown 下载（静态内容，无 API，见 §11） |

## 3. 仪表盘（dashboard）

| 元素 | 数据来源 |
|------|----------|
| 统计卡片：项目数、有效密钥数、7 天内到期密钥数、今日认证次数（成功/失败） | `GET /stats` |
| 最近认证事件表（时间/项目/结果/指纹/IP，最近 10 条） | `GET /audit-logs?event_type=auth.authenticate&size=10` |
| 即将过期密钥提示条（7 天内，黄色徽章；已过期红色） | `GET /stats` 的 expiring_keys_7d |

交互：卡片可点击跳转对应管理视图（如"项目数"→ 项目视图）。

## 4. 项目管理（projects 视图）

| 元素 | 说明 |
|------|------|
| 工具栏 | 搜索框（按名称）、「新建项目」按钮 |
| 列表 | 名称、当前版本、密钥数、状态徽章（启用/停用）、创建时间；行操作：查看密钥 / 编辑 / 停用 / 删除 |
| 新建/编辑模态框 | 名称（必填，唯一）、描述、当前版本、最低版本（可选） |

交互流程：
```
进入视图 → GET /projects?page=1&size=20 → 渲染列表
新建 → POST /projects → 成功 → 刷新列表
编辑 → PUT /projects/{id}
停用/启用 → PUT /projects/{id} {is_active: !cur}
删除 → 二次确认 → DELETE /projects/{id} → 提示"将级联删除其全部密钥"
查看密钥 → 记录 state.currentProject → 切换到密钥列表（见 §5）
```

API：`GET/POST /projects`、`GET/PUT/DELETE /projects/{id}`。错误：409/20201 名称冲突提示改名字。

## 5. 密钥管理（keys 视图）

| 元素 | 说明 |
|------|------|
| 面包屑 | 返回项目列表；显示当前项目名 |
| 工具栏 | 「生成密钥」按钮；状态筛选（全部/启用/停用/已过期） |
| 列表 | 备注、绑定指纹（有/无徽章）、过期时间（相对提示：`2027-01-01` / `7 天后` / `已过期`）、状态、最后使用时间/IP、创建时间；行操作：编辑 / 轮换 / 禁用 / 吊销 |
| 生成模态框 | 备注（必填）、过期时间（datetime-local，可留空=永不过期）、指纹（可选绑定）；确认后请求 |
| 明文展示模态框 | 密钥等宽字体 + 复制按钮 + 红色警示「仅显示一次，关闭后不可再查看」 |
| 编辑模态框 | 备注、过期时间、指纹、状态（启用/禁用） |
| 轮换确认框 | 提示"生成新密钥，旧密钥保留 7 天宽限期后失效" |

交互流程（生成）：
```
生成 → POST /projects/{id}/keys
     → 响应含 key_value（唯一一次）
     → 打开明文模态框 → 用户复制 → 关闭（此后列表中不可见明文）
```

交互流程（轮换）：
```
轮换 → POST /keys/{id}/rotate
     → 同样展示新密钥一次；列表出现新旧两条（旧密钥标记"轮换中，x 天后失效"）
```

API：`GET/POST /projects/{id}/keys`、`PUT /keys/{id}`、`POST /keys/{id}/rotate`、`DELETE /keys/{id}`。
安全约束（JS 侧）：明文密钥只存在于模态框 DOM 中，关闭即清空；不写入 localStorage/内存变量。

## 6. 审计日志（audit 视图）

| 元素 | 说明 |
|------|------|
| 筛选区 | 事件类型下拉（login/project_*/key_*/auth.authenticate…）、结果（全部/成功/失败）、时间范围（起止 datetime-local） |
| 表格 | 时间、事件类型、操作者、目标、结果（成功/失败徽章）、IP、请求 ID（可展开查看 detail JSON） |
| 分页 | 上一页/下一页 + 页码 + 总数 |

交互：筛选条件变化 → `GET /audit-logs?event_type=&result=&from=&to=&page=&size=` 重新拉取。
API：`GET /audit-logs`。

## 7. 修改密码（password 视图）

| 元素 | 说明 |
|------|------|
| 表单 | 旧密码、新密码（≥12 位，含字母与数字，实时强度提示）、确认新密码 |
| 提示 | 提交成功后将退出登录，需用新密码重新登录 |

交互：`PUT /admin/password` → 成功 → 清 cookie 跳登录页。

## 8. 通用错误处理策略

| 场景 | 处理 |
|------|------|
| 401/20103（会话过期） | api.js 统一跳登录页 |
| 429（限流） | toast "操作过于频繁，请稍后再试" |
| 400/409 | toast 展示 message（如名称冲突） |
| 网络错误/5xx | toast "服务暂不可用，请稍后重试" |
| 密钥明文展示 | 仅在模态框存活期间保留，关闭即清除 |

## 9. 前端验收清单

- [ ] 未登录访问 index.html 自动跳登录页；已登录访问 login.html 自动进主页
- [ ] 登录失败提示明确；连续失败触发限流提示
- [ ] 项目 CRUD、启停用、级联删除确认完整可用
- [ ] 密钥生成后明文仅一次展示、可复制；列表永不显示明文
- [ ] 过期时间可设可改、永不过期（空）可用；列表正确显示到期状态
- [ ] 指纹可绑定/解绑；绑定后认证失败可在审计中看到 fingerprint_mismatch
- [ ] 轮换产生新旧两密钥，旧密钥在宽限期内仍可认证（后端行为，界面仅提示）
- [ ] 审计页筛选/分页正确；detail 可展开
- [ ] 全部资源本地化（无外部 URL），内嵌进二进制后功能完整
- [ ] 「使用教程」视图七个小节渲染完整，TOC 锚点滚动正常，内容与界面实际交互一致（§10）
- [ ] 「对接文档」视图内容与下载的 MD 同源一致，下载文件中文无乱码且可直接交付（§11）
- [ ] 教程/文档两视图同样受会话守卫保护，未登录访问仍跳登录页（§10/§11）

> 设计文档：`Documents/newInterfaceDesign/01-管理员使用教程界面设计.md`
> 实现：`FrontEnd/js/guide.js`（静态数据 + 渲染，无任何 API 调用）

| 项 | 说明 |
|----|------|
| 视图 id / 标题 | `guide` / 「使用教程」 |
| 内容 | 七个小节：部署登录、仪表盘、项目管理、密钥管理、审计日志、修改密码、安全红线 |

## 11. 对接文档视图（docs）

> 设计文档：`Documents/newInterfaceDesign/02-接入方对接文档界面设计.md`
> 实现：`FrontEnd/js/docs.js`（单源内容数据 + 双渲染器 + MD 下载，无任何 API 调用）

| 项 | 说明 |
|----|------|
| 视图 id / 标题 | `docs` / 「对接文档」 |
| 内容 | 十一节对接文档（概述、Base URL、认证接口、错误码、校验顺序、字段详解、JWT、限流与审计、调用示例、排查表、安全建议） |
| 单源模型 | `DOC_SECTIONS` 结构化为唯一事实源，页面渲染（`renderDocsHtml`）与 MD 构建（`buildMarkdown`）遍历同一份数据，保证「页面 = 下载 MD」 |
| 块类型 | `p` / `steps` / `ul` / `table` / `code` / `note` / `h3` / `h4` |
| 下载 | `Blob` + `URL.createObjectURL` + 隐藏 `<a>` 触发；文件名 `AuthCenter-接入对接文档.md`；加 `\ufeff` BOM 防 Windows 记事本中文乱码 |
| 交付物 | 下载的 MD 与 `Documents/newInterfaceDesign/attachments/AuthCenter-接入对接文档.md` 成品逐字一致，可脱离平台直接交付开发人员 |
| 安全 | 页面渲染统一 `escapeHtml()` 后仅还原 `**粗体**` 与行内 `` `code` ``，无用户输入、无外部资源 |
