# 01 前端总体设计

> 前端架构文档 1/2 ｜ 弱前端：原生三件套，无框架、无构建步骤

## 1. 目标与范围

- 定位：管理员操作界面（决策 C5「弱前端」），**不面向公网用户**。
- 功能范围：管理员登录、仪表盘、项目管理、密钥管理（生成/过期时间/备注/启停/轮换/吊销）、审计日志查询、修改密码。
- 约束：原生 HTML5 + CSS3 + Vanilla JS；**无 npm/打包器/CDN**，离线可用；随后端二进制内嵌发布。

## 2. 页面结构（多页面方案）

```
FrontEnd/
├── login.html          # 登录页（独立）
├── index.html          # 管理主界面（登录后进入）
├── css/
│   ├── base.css        # 变量、reset、布局、组件（按钮/表格/表单/模态框/徽章）
│   └── auth.css        # 登录页专用样式
└── js/
    ├── api.js          # fetch 封装、统一错误处理、会话判断、时间格式化
    ├── login.js        # 登录逻辑
    ├── app.js          # 主界面框架：导航、路由切换、当前用户、登出
    ├── dashboard.js    # 仪表盘视图
    ├── projects.js     # 项目视图（列表/表单/密钥入口）
    ├── keys.js         # 密钥视图（列表/生成/编辑/轮换/吊销，含"仅显示一次"逻辑）
    ├── audit.js        # 审计视图（筛选/分页）
    └── common.js       # DOM 工具、模态框、toast、表单校验（可选合并进 app.js）
```

> 决策：**多页面 + 视图切换**——`login.html` 独立；`index.html` 内用 JS 切换「仪表盘/项目/密钥/审计/改密」5 个视图（隐藏 div 或 `hidden` 属性切换），避免引入前端路由库，符合弱前端定位。

## 3. 与后端交互约定

| 项 | 约定 |
|----|------|
| API 地址 | 同源相对路径 `/api/v1/...`（页面与 API 同端口 53779，无跨域） |
| 鉴权 | `fetch(..., {credentials: 'same-origin'})` 自动携带 `auth_session` cookie |
| 响应处理 | api.js 统一：`res.json()` → `code!==0` 时 toast 错误并按码处理；401 跳转登录页 |
| 时间显示 | 后端 UTC ISO8601 → 前端 `new Date(x).toLocaleString()` 本地时区 |
| 密钥明文 | 仅生成/轮换响应中出现一次；前端展示后**不入内存/不落 localStorage**，提供「复制」按钮 |

```js
// js/api.js 核心（示意）
async function api(path, {method='GET', body}={}) {
  const res = await fetch('/api/v1' + path, {
    method, credentials: 'same-origin',
    headers: body ? {'Content-Type': 'application/json'} : {},
    body: body ? JSON.stringify(body) : undefined,
  });
  const json = await res.json().catch(() => ({code: 50000, message: '响应解析失败'}));
  if (res.status === 401 || json.code === 20103) { location.href = '/login.html'; throw new Error('会话过期'); }
  if (json.code !== 0) throw Object.assign(new Error(json.message), {code: json.code});
  return json.data;
}
```

## 4. 会话与登录跳转

- `login.html` 加载时调 `GET /api/v1/admin/me`：已登录 → 跳 `index.html`。
- `index.html` 加载时调 `GET /api/v1/admin/me`：未登录 → 跳 `login.html`；成功则缓存用户名到内存变量。
- 登出：`POST /api/v1/admin/logout` → 跳登录页。
- 会话过期（任意 API 返回 401/20103）：统一跳登录页并提示。

## 5. 状态管理（轻量）

不引入框架状态库，用模块级变量 + 事件：

```js
// app.js 内
const state = { user: null, currentProject: null, keysCache: {} };
// 视图切换：showView('projects')；编辑项目时记录 state.currentProject
```

- 密钥列表在进入项目时重新拉取（不强缓存，保证与其他管理员操作同步）。
- 审计/仪表盘每次进入视图刷新。

## 6. 内嵌发布机制

- 开发期：`go run ./cmd/authcenter -web-dir ../FrontEnd`，改前端文件即刷新生效；或任意静态服务器打开。
- 发布期：构建脚本复制 `FrontEnd/*` → `BackEnd/internal/web/` → `go:embed` 进二进制（详见《07》§2）。
- 因此前端代码**不得引用任何外部 URL 资源**（字体/图标/库），保证离线与内嵌可用。

## 7. 视觉与体验规范

- 简洁后台风格：侧边导航 + 内容区；系统字体栈；深色/浅色可选（默认浅色，纯 CSS 变量便于切换，P2）。
- 危险操作（删除项目/吊销密钥）需二次确认模态框。
- 密钥明文展示模态框：等宽字体、复制按钮、醒目提示「仅显示一次，关闭后不可再次查看」。
- 空状态、加载态、错误态（toast）三态齐全。
