# AuthCenter — 中心认证服务 设计文档集

> 版本：v0.1（设计稿）｜ 状态：待评审 ｜ 语言：简体中文

## 1. 项目一句话概述

AuthCenter 是一个**强后端、弱前端**的内部中心认证服务：纯 Go 实现后端，只监听本机 `127.0.0.1:53779`（HTTP），对外 HTTPS 由 Caddy 反代；其他项目程序携带「项目名 + 版本号 + 指纹 + 分配密钥」调用认证接口，后端校验后返回认证结果（可选签发短期访问令牌）；管理员通过一个原生 HTML+CSS+JS 的轻量前端完成登录、项目与密钥的完整生命周期管理，并查看全量审计日志。

## 2. 核心约束（需求红线）

| # | 约束 | 说明 |
|---|------|------|
| C1 | 纯 Go，禁止 cgo | 所有依赖必须为纯 Go 实现，`CGO_ENABLED=0` 可交叉编译，避免交叉编译问题 |
| C2 | 仅监听 `127.0.0.1:53779`，HTTP | HTTPS 一律交给外置 Caddy |
| C3 | 启动自动创建 admin | 密码为 30 位纯随机文本；已存在则跳过（幂等） |
| C4 | 对外认证接口 | 输入：项目名、版本号、指纹、密钥；输出：认证结果 |
| C5 | 弱前端 | 一个或多个 html+css+js 即可，覆盖管理员登录、密钥生成、过期时间管理、备注等管理操作 |
| C6 | Bundle 双平台产物 | `Bundle/windows` 与 `Bundle/linux` 各放一份完整可执行产物，前后端产物同时复制到两个目录 |

## 3. 已确认的设计决策（用户拍板）

| # | 决策点 | 结论 |
|---|--------|------|
| D1 | 认证返回形式 | **结果 + 可选令牌**：默认仅返回认证结果；请求参数 `issue_token=true` 时额外签发短期 JWT |
| D2 | 审计日志 | **完整审计**：管理员登录/登出、项目与密钥增删改、外部认证成功/失败（含指纹与 IP），管理界面可查询 |
| D3 | admin 初始密码交付 | 首次启动打印到**控制台**并写入数据目录 `auth.log`，之后不再展示 |
| D4 | 密钥管理模型 | **一项目多密钥**：支持多密钥、轮换、单独过期时间/备注、启用/禁用、指纹绑定 |

## 4. 技术选型总览

| 层次 | 选型 | 理由 |
|------|------|------|
| 语言 | Go 1.22+（标准库为主） | 纯 Go、跨平台、单二进制 |
| SQLite 驱动 | `modernc.org/sqlite`（纯 Go） | 唯一无需 cgo 的成熟 SQLite 驱动，支持 `CGO_ENABLED=0` 交叉编译 |
| 密码哈希 | `golang.org/x/crypto/argon2`（argon2id） | 纯 Go、抗 GPU 暴力破解；避免 bcrypt 的 72 字节限制 |
| 令牌 | `github.com/golang-jwt/jwt/v5` | 纯 Go、业界标准 |
| 限流 | `golang.org/x/time/rate` | 纯 Go 令牌桶 |
| 路由 | 标准库 `net/http`（Go 1.22+ 增强 ServeMux） | 无需第三方 Web 框架 |
| 日志 | 标准库 `log/slog` | 结构化日志 |
| 静态资源嵌入 | 标准库 `embed` | 前端 html/css/js 内嵌进后端二进制，单一端口同时服务页面与 API |
| 前端 | 原生 HTML5 + CSS3 + Vanilla JS | 无框架、无构建步骤、无 CDN 依赖，离线可用 |
| HTTPS | Caddy（外置） | 反代 `127.0.0.1:53779`，自动证书 |

> 依赖红线：所有第三方库必须**纯 Go**（`go list -deps` 检查无 `CGO` 引用），详见《08-测试与验收计划》。

## 6. 顶层目录结构（目标态）

```
authCenter/
├── BackEnd/                 # Go 后端模块（独立 go module）
├── FrontEnd/                # 前端静态资源（html/css/js）
├── Bundle/

│   └── linux/               # Linux 可执行产物（后端二进制 + 前端静态文件副本）
├── Documents/               # 本文档集
└── build.ps1 / build.sh     # 构建与 bundle 脚本（详见后端文档 07）
```
