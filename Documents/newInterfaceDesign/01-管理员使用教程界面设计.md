# 01 管理员使用教程界面设计

> 新界面设计 1/3 ｜ 界面一：针对管理员的前端使用完整教程
> 定位：登录后即可查看的内置帮助，替代「翻外部文档」；新管理员零基础可上手。

## 1. 设计目标与原则

- **目标**：把当前管理界面（登录、仪表盘、项目、密钥、审计、改密）的完整使用流程、
  每步操作、安全红线，以分节教程形式内置于界面，管理员无需离开系统即可学会全部操作。
- **原则**：
  - **零后端依赖**：内容为纯静态，不调用任何 API（`guide.js` 只渲染数据，不产生网络请求）；
  - **复用现有组件**：全部使用 `base.css` 已有类（card/btn/badge/table/warning…），保持视觉一致；
  - **危险操作显性化**：删除项目、吊销密钥、轮换等高风险操作单独红框提示；
  - **跟随现状**：教程内容以当前 `FrontEnd/` 实际交互为准（与 `02-页面与交互设计.md` 逐项对应）。

## 2. 融入方式（三处接入点，完全沿用现有约定）

| # | 接入点 | 现有机制 | 新增内容 |
|---|--------|----------|----------|
| 1 | `index.html` 侧边导航 | `<a data-view="...">`（见 02 §2） | 新增 `<a data-view="guide">📖 使用教程</a>` |
| 2 | `index.html` 内容区 | `<section id="view-xxx" class="view">` | 新增 `<section id="view-guide"><div id="guide-root"></div></section>` |
| 3 | `app.js` 视图注册 | `VIEW_TITLES` / `VIEW_LOADERS`（见 01 §2） | 加 `guide: '使用教程'` 与 `guide: loadGuide` |
| 4 | `js/guide.js` | 各视图 JS 模式（`loadXxx()` 挂到 `#xxx-root`） | 新文件：数据 + 渲染 |

导航顺序建议：`仪表盘 → 项目 → 审计日志 → 修改密码 → 使用教程 → 对接文档`，
教程与对接文档放最后（属于「辅助/学习」类，不干扰日常操作路径）。

## 4. 数据与渲染设计（guide.js）

```js
/* js/guide.js — 管理员使用教程（静态内容，无 API） */
const GUIDE_SECTIONS = [
  {
    id: 'setup',
    title: '1. 首次部署与登录',
    blocks: [ /* 见 §5 内容大纲 */ ],
  },
  // ...
];

function loadGuide() {
  const root = document.getElementById('guide-root');
  // 渲染左 TOC + 右内容；块类型渲染器见下
  root.innerHTML = renderGuide();
  bindTocScroll();   // 点击锚点平滑滚动
}
```

内容块（block）类型约定（`guide.js` 内统一渲染器，后续新增小节只加数据）：

| 块类型 | 渲染为 | 对应场景 |
|--------|--------|----------|
| `p` 段落 | `<p>` | 说明文字 |
| `steps` 步骤列表 | `<ol class="guide-steps">` | 操作步骤 |
| `tip` / `warn` 提示 | `<div class="callout callout-tip/warn">` | 注意事项 / 红线警告 |
| `table` 表格 | `<table class="table">` | 字段/选项对照 |
| `img` 截图占位 | `<div class="guide-shot">（截图占位：描述）</div>` | 预留界面截图位 |

> 安全：所有动态内容过 `escapeHtml()`；教程数据内嵌于 JS 常量，无用户输入，但仍按
> 现有规范统一转义（见 `common.js`）。

## 5. 教程内容完整大纲（与现状逐项核对）

### §1 首次部署与登录
1. 部署启动（两种形态）：
   - 发布包：`Bundle/{windows,linux}` 目录运行 `authcenter(.exe) -data-dir ./data`；
   - 系统服务：Windows NSSM / Linux systemd（见 `deploy/` 示例）。
2. 获取初始密码：首次启动打印在**控制台**，并写入 `data/auth.log`（30 位随机，仅此一次，重启不重复）。
   ⚠ warn：初始密码丢失无法找回，只能删除 `data/authcenter.db` 重新初始化（会清空全部数据）。
3. 登录：浏览器访问 `http://127.0.0.1:53779` → 用户名 `admin` + 初始密码。
4. 登录失败提示：连续失败触发锁定（每 IP 5 次/分钟、同用户名失败 5 次锁 15 分钟）→ 提示「尝试过于频繁，请 15 分钟后再试」。
5. 登出：右上角「登出」。

### §2 仪表盘
- 四张统计卡：项目数 / 有效密钥数 / 7 天内到期密钥 / 今日认证（成功、失败），点击卡片可跳对应管理视图；
- 最近认证事件表（最近 10 条外部认证：时间/项目/结果/指纹/IP）；
- 7 天内到期密钥黄色提示条（⚠ 需尽快轮换）。

### §3 项目管理
| 操作 | 步骤 | 注意 |
|------|------|------|
| 新建项目 | 项目 → ＋新建项目 → 名称/描述/当前版本/最低版本 → 保存 | 名称唯一，外部认证以 `project_name` 精确匹配 |
| 搜索 | 名称关键词 → 回车/搜索 | — |
| 编辑 | 编辑 → 修改描述/版本/最低版本 → 保存 | 名称不可改（唯一标识） |
| 停用/启用 | 停用/启用按钮 | 停用后外部认证返回 `project_disabled` |
| 删除 | 删除 → 二次确认 | ⚠ warn：**级联删除该项目全部密钥，不可恢复** |

> tip：`min_version` 留空 = 不限制版本；填写后低于该版本的客户端认证返回 `version_too_old`。

### §4 密钥管理
1. 进入：项目列表 → 「查看密钥」。
2. 生成密钥：＋生成密钥 → 备注（必填）/过期时间（留空=永不过期）/绑定指纹（可选）→ 保存。
   - ⚠ warn：**明文仅显示一次**，关闭后不可再查看，必须立即复制保存；
   - 列表永不显示明文（只能看到备注/指纹/过期/状态/最后使用）。
3. 编辑：改备注/过期时间/指纹/状态（编辑时留空指纹 = 解绑）。
4. 启停：禁用后外部认证返回 `key_disabled`。
5. 轮换：⚠ 二次确认 → 生成新密钥（明文一次展示），**旧密钥保留 7 天宽限期**（宽限期内仍可认证，期满自动失效）；
   - 适用场景：密钥疑似泄露、例行换密、到期前预防性轮换。
6. 吊销：⚠ 二次确认 → **立即失效**，使用该密钥的客户端即刻无法认证。
7. 状态筛选：全部/启用/停用/已过期；过期时间徽章：`永不过期 / N 天后（黄）/ 已过期（红）`。

### §5 审计日志
- 筛选：事件类型（登录/项目/密钥/认证…）/结果（成功/失败）/时间范围/关键词；
- 表格：时间/事件/操作者/目标/结果/IP/请求 ID；
- 点击请求 ID 可展开 detail JSON（失败原因、指纹、版本等）；
- 分页：上一页/下一页 + 总数。
- 常用排查：外部认证失败 → 筛选 `auth.authenticate_failed` → 展开 detail 看 `reason`。

### §6 修改密码
- 新密码要求：≥ 12 位且**同时包含字母与数字**（有实时强度提示）；
- 提交成功后将**退出登录**，需用新密码重新登录；
- 建议：拿到初始密码后第一件事就是改密。

### §7 安全红线（必读）
| 红线 | 说明 |
|------|------|
| 🔴 密钥明文只展示一次 | 生成/轮换后立即复制；关闭模态框即无法找回 |
| 🔴 初始密码立即修改 | 首次登录后立刻改密，勿长期使用打印在控制台的密码 |
| 🔴 删除项目/吊销密钥不可逆 | 操作前确认级联影响（项目删除=全部密钥失效；吊销=立即失效） |
| 🟡 密钥轮换纪律 | 到期前、疑似泄露时及时轮换；宽限期内新旧密钥并行，便于灰度 |
| 🟡 指纹绑定 | 高价值项目建议绑定指纹，防密钥被拷走异地使用 |
| 🟡 会话安全 | 会话 7 天有效；改密会注销全部会话；不要在公用机器长期保持登录 |
| 🟡 端口不对外 | 服务仅监听 `127.0.0.1:53779`，勿开放入站防火墙端口；对外一律走 Caddy HTTPS 反代 |

## 6. 交互细节

- **锚点导航**：TOC 点击 → `scrollIntoView({behavior:'smooth'})`；滚动时高亮当前小节（可选 IntersectionObserver，P2）；
- **展开/折叠**：默认全部展开；提供「全部展开/收起」按钮（可选，P2）——教程页信息量大，展开阅读为主；
- **空态/加载态**：教程为静态内容，无加载态；渲染失败（理论不会）走 `toastError` 兜底。
