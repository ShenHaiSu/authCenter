# 新界面设计集 —— 管理员使用教程 + 接入方对接文档

> 版本：v1.0（设计稿）｜ 状态：待评审 ｜ 语言：简体中文
> 定位：为现有 AuthCenter 管理前端（`FrontEnd/`）新增两个交互界面的**完整设计文档**。
> 本设计**仅输出设计，不修改任何实际代码文件**；落地实施时按《03》执行。

## 1. 设计目标

在现有「弱前端」架构（原生 HTML5 + CSS3 + Vanilla JS，无框架、无构建、无外部资源）内，
新增两个纯静态信息型界面，解决两类真实痛点：

| 界面 | 面向对象 | 解决什么问题 | 关键能力 |
|------|----------|--------------|----------|
| 界面一：管理员使用教程 | 本系统管理员（含新接手管理员） | 现有管理界面无任何内置说明，操作依赖外部文档，新管理员上手成本高 | 完整图文教程、分节导航、危险操作红线提示 |
| 界面二：接入方对接文档 | 其他项目的开发人员 | 其他项目要对接认证后端，却拿不到可脱离平台传递的接口文档 | 页面内完整对接文档 + **一键下载 Markdown**，可脱离平台直接交付 |

两个界面都**无需新增任何后端 API**（纯前端静态内容），因此不改动 `BackEnd/` 一行 Go 代码。

## 2. 融入方式（核心设计决策）

遵循现有「多页面 + 视图切换」约定（见 `Documents/frontEndArchitect/01 §2、02 §2`），
两个界面均作为 `index.html` 内的**新视图（view）** 融入，而不是新开独立 HTML 页面：

- 复用 `index.html` 的登录守卫与整体布局（侧边栏 + 顶栏 + 内容区），零新增会话逻辑；
- 完全按现有「三处接入点」标准扩展（详见《01》§2 /《02》§2）；
- 复用 `base.css` 全部现有组件类（card / btn / badge / table / modal / toast / breadcrumb…），仅追加少量新样式；
- 复用 `common.js` 工具（`$` / `escapeHtml` / `toast` / `confirmAction`…）。

> 理由：两界面都属于「管理员登录后可见」的内容，作为视图融入可自动获得：
> 未登录跳转登录页（api.js 的 `/admin/me` 守卫）、统一顶栏用户名/登出、响应式侧边栏，且不增加页面数。
