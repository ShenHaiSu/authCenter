## 2. 表结构（DDL，目标态）

> 时间一律存 **UTC**（`TEXT` ISO8601，如 `2026-01-01T00:00:00Z`）；迁移用 `CREATE TABLE IF NOT EXISTS`，追加式演进。

### 2.1 admin_user（管理员）

```sql
CREATE TABLE IF NOT EXISTS admin_user (
    id             INTEGER PRIMARY KEY AUTOINCREMENT,
    username       TEXT    NOT NULL UNIQUE,            -- 登录名，内置固定为 'admin'
    password_hash  TEXT    NOT NULL,                   -- argon2id 编码串
    is_active      INTEGER NOT NULL DEFAULT 1,         -- 1 启用 0 停用（预留 P2）
    created_at     TEXT    NOT NULL,
    last_login_at  TEXT,
    last_login_ip  TEXT
);
```

### 2.2 admin_session（管理员会话）

```sql
CREATE TABLE IF NOT EXISTS admin_session (
    id             INTEGER PRIMARY KEY AUTOINCREMENT,
    token_hash     TEXT    NOT NULL UNIQUE,            -- 会话 token 的 SHA-256，库中不存明文
    admin_user_id  INTEGER NOT NULL REFERENCES admin_user(id) ON DELETE CASCADE,
    expires_at     TEXT    NOT NULL,
    ip             TEXT,
    user_agent     TEXT,
    created_at     TEXT    NOT NULL
);
CREATE INDEX IF NOT EXISTS idx_session_user ON admin_session(admin_user_id);
CREATE INDEX IF NOT EXISTS idx_session_expire ON admin_session(expires_at);  -- 清理过期用
```

### 2.3 project（项目）

```sql
CREATE TABLE IF NOT EXISTS project (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    name            TEXT    NOT NULL UNIQUE,           -- 项目名（外部认证的标识，如 "my-service"）
    description     TEXT,
    current_version TEXT,                              -- 当前维护的版本（认证记录与展示用）
    min_version     TEXT,                              -- 可选：允许认证的最低版本（语义化比较，NULL=不限制）
    is_active       INTEGER NOT NULL DEFAULT 1,
    created_at      TEXT    NOT NULL,
    updated_at      TEXT    NOT NULL
);
```

### 2.4 api_key（项目密钥）

```sql
CREATE TABLE IF NOT EXISTS api_key (
    id             INTEGER PRIMARY KEY AUTOINCREMENT,
    project_id     INTEGER NOT NULL REFERENCES project(id) ON DELETE CASCADE,
    name           TEXT    NOT NULL DEFAULT '',        -- 备注/用途（如 "生产环境"、"Server-A"）
    key_value      TEXT    NOT NULL,                   -- 密钥明文或密文（见 §4 存储策略）
    fingerprint    TEXT,                               -- 绑定指纹，NULL=不绑定（任意指纹可认证）
    expires_at     TEXT,                               -- NULL=永不过期
    last_used_at   TEXT,
    last_used_ip   TEXT,
    is_active      INTEGER NOT NULL DEFAULT 1,
    created_by     TEXT    NOT NULL DEFAULT 'admin',
    created_at     TEXT    NOT NULL
);
CREATE INDEX IF NOT EXISTS idx_key_project   ON api_key(project_id);
CREATE INDEX IF NOT EXISTS idx_key_value     ON api_key(key_value);          -- 认证查主键
CREATE INDEX IF NOT EXISTS idx_key_expire    ON api_key(expires_at);
```

### 2.5 audit_log（审计日志）

```sql
CREATE TABLE IF NOT EXISTS audit_log (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    event_time  TEXT    NOT NULL,
    event_type  TEXT    NOT NULL,      -- 枚举见 §5
    actor_type  TEXT    NOT NULL,      -- 'admin' | 'client'
    actor_id    TEXT,                  -- 管理员 id / 项目名
    actor_name  TEXT,
    target_type TEXT,                  -- 'project' | 'api_key' | 'session' | 'system' | 'audit'
    target_id   INTEGER,
    target_name TEXT,
    result      TEXT    NOT NULL,      -- 'success' | 'failure'
    detail      TEXT,                  -- JSON：失败原因、指纹、认证版本等
    ip          TEXT,
    request_id  TEXT
);
CREATE INDEX IF NOT EXISTS idx_audit_time  ON audit_log(event_time);
CREATE INDEX IF NOT EXISTS idx_audit_type  ON audit_log(event_type);
CREATE INDEX IF NOT EXISTS idx_audit_actor ON audit_log(actor_id);
```

### 2.6 settings（系统设置）

```sql
CREATE TABLE IF NOT EXISTS settings (
    key        TEXT PRIMARY KEY,
    value      TEXT NOT NULL,
    updated_at TEXT NOT NULL
);
-- 初始化项：jwt_secret（随机 32B base64）、token_ttl_seconds（默认 86400）、
--           require_fingerprint（"0"/"1"，是否强制密钥绑定指纹，默认 0）
```

## 3. 认证查询设计（性能）

认证接口（F-008）核心 SQL：

```sql
SELECT k.id, k.key_value, k.fingerprint, k.expires_at, k.is_active,
       p.id AS project_id, p.name, p.is_active AS project_active, p.current_version
FROM api_key k JOIN project p ON p.id = k.project_id
WHERE p.name = ? AND k.key_value = ?;   -- 走 idx_key_value 与 project.name UNIQUE
```

内存中完成后续判断（启用状态、过期、指纹），逻辑简单、可控。

## 4. 密钥存储策略（重要安全决策）

| 方案 | 说明 | 取舍 |
|------|------|------|
| **默认：明文存储** | `key_value` 存明文；依赖 `data/` 目录权限（POSIX 0700，Windows 用户目录 ACL）+ 服务不对外网开放 | 管理员可随时查看/复制密钥；风险=DB 文件泄露即密钥泄露 |
| 可选（P2/F-021）：AES-GCM 加密 | 密钥列加密，密钥来自 env `AUTHCENTER_KEY_ENCRYPTION_KEY`；丢失 env 则历史密钥不可恢复 | 增加运维复杂度 |

**默认采用明文 + 权限防护**，理由：内部工具、密钥本就需在管理界面复制下发；DB 单文件仅本机可读。文档明示风险，预留加密升级路径（迁移时 `key_encrypted` 标记列）。

## 5. 审计事件类型枚举（event_type）

| 分类 | 事件 |
|------|------|
| 管理员 | `admin.login` `admin.logout` `admin.login_failed` `admin.password_change` |
| 项目 | `project.create` `project.update` `project.delete` `project.disable` `project.enable` |
| 密钥 | `key.create` `key.update` `key.disable` `key.enable` `key.rotate` `key.delete` |
| 外部认证 | `auth.authenticate` `auth.authenticate_failed` |
| 系统 | `system.startup` `system.admin_initialized` `system.shutdown` |

## 6. SQLite 实践规范

| 项 | 值 | 说明 |
|----|----|------|
| journal_mode | WAL | 读写并发更好，崩溃恢复 |
| busy_timeout | 5000ms | 写锁等待，避免 `database is locked` |
| foreign_keys | ON | 每次连接设置 |
| 事务 | 写操作单事务包裹 | 如 `key.create`（写密钥+写审计） |
| 并发 | `db.SetMaxOpenConns(1)` 或写串行化 | 本机单实例，单连接即可，规避锁竞争；读多可调 2-4 |
| 迁移 | 启动时顺序执行幂等 DDL | 追加式，不做破坏性变更；后续可加 `schema_version` 表 |
| 备份 | 文档化：`sqlite3 .backup` 或直接复制 WAL 落盘后的 db 文件 | 数据目录整体备份 |

## 7. 数据保留

- 审计日志：默认保留 180 天，`settings.audit_retention_days` 可配（P2 自动清理任务，可 cron 或启动时清理）。
- 会话：过期后由登录/查询时惰性清理 + 每日清理任务。
