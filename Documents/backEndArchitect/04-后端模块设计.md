```

    │   ├── audit_service.go     # 审计写入/查询
    │   └── stats_service.go     # 仪表盘统计（P2）
```

依赖规则：`httpapi → service → store → database`；`model` 被各层引用；`service` 间通过接口/直接调用（如 audit_service 被其他 service 注入）。

## 3. 核心业务逻辑

### 3.1 admin 初始化（F-002/F-003，幂等）

```
func EnsureAdmin(ctx, store, logger) (created bool, plainPassword string, err error):
    if store.AdminExists("admin"):
        return false, "", nil            // 已存在：什么都不做
    plain := randomString(30)            // crypto/rand，字符集 A-Za-z0-9（62 种）
    hash := argon2id.Hash(plain)         // 见《06》§3
    store.CreateAdmin("admin", hash)
    logger.Warn("admin initialized", ...) // 必现级别
    writeToLogFile(data/auth.log, "初始管理员密码: "+plain)  // D3
    return true, plain, nil
```

- 密码字符集：`A-Za-z0-9`（62 字符），30 位 → 熵 ≈ 178 bit，纯随机不可预测。
- **幂等**：`AdminExists` 判断（username='admin' 即存在），重启不会重复生成。
- 交付：main 函数同时打印到控制台；落盘文件 `auth.log` 权限 0600。

### 3.2 外部认证校验链（F-008，核心）

```
func (s *AuthService) Authenticate(req AuthenticateRequest) (result, error):
    // 输入：ProjectName, Version, Fingerprint, Key, IssueToken
    // 顺序严格如下（失败即返回，全部写审计）
    1. 限流检查（IP 维度）                        → 超限: rate limited
    2. store.GetProjectByName(name)               → 不存在: project_not_found
    3. project.IsActive?                          → 否: project_disabled
    4. 版本校验：min_version 语义化比较（可选）      → 低于: version_too_old
    5. store.GetKeyByValue(key)                   → 不存在: key_not_found
    6. key.ProjectID == project.ID ?              → 否: key_mismatch
    7. key.IsActive?                              → 否: key_disabled
    8. key.ExpiresAt 未过期（NULL 永不过期）        → 否: key_expired
    9. 指纹校验：
       - key.Fingerprint 非空 → 必须相等           → 否: fingerprint_mismatch
       - key.Fingerprint 为空 → 通过
       - settings.require_fingerprint=1 且 key 未绑定 → 否: fingerprint_required
    10. 更新 last_used_at / last_used_ip（异步或同事务）
    11. 审计 success；返回项目信息 + current_version
    12. 若 IssueToken：tokenService.Issue(project, key) → 附带 {token, expires_at}
```

### 3.3 令牌签发（F-013 / D1）

- 算法：HS256；secret：首次启动随机 32B，存 `settings.jwt_secret`（可 env 覆盖）。
- Claims：`{sub: "project:{name}", pid: project_id, kid: key_id, ver: version, iat, exp, jti}`。
- TTL：`settings.token_ttl_seconds`，默认 86400（24h）。
- 校验方：调用方项目自持 secret 或调用本服务 `GET /api/v1/token/verify`（P2，可选）——设计上提供**本地校验**为先（客户端用 secret 校验），远程校验接口列为 P2。

### 3.4 会话与管理员鉴权（F-004）

- 登录成功 → 生成 32B 随机 token → 存 `SHA-256(token)` 到 `admin_session`（过期 7 天）→ 写入 httpOnly + SameSite=Lax cookie（`auth_session`）。
- 中间件 `RequireAdmin`：读 cookie → 哈希查会话 → 校验过期 → 注入当前用户到 context；失败返回 401。
- 登出：删除会话行 + 清 cookie。
- 改密：校验旧密码 → 新密码 argon2id → 更新 → 使该用户所有会话失效（删 session）。

### 3.5 密钥生命周期（F-006/F-015）

```
生成   POST /api/v1/projects/{id}/keys
        → crypto/rand 40 位（A-Za-z0-9，熵 238bit）→ 明文仅本次响应返回
        → 管理员需立即复制保存（界面提示"仅显示一次"）
编辑   PUT /api/v1/keys/{id}      # 备注/过期时间/指纹/启停
轮换   POST /api/v1/keys/{id}/rotate
        → 新密钥生效；旧密钥进入"轮换保留期"（默认 7 天，settings 可配）
        → 保留期内旧密钥仍可认证（兼容灰度切换），期满自动禁用
吊销   DELETE /api/v1/keys/{id}   # 立即失效（is_active=0，软删），可恢复（P2）
```

## 4. HTTP 层设计

### 4.1 路由注册（Go 1.22 增强 ServeMux）

```go
mux.HandleFunc("POST /api/v1/authenticate", h.Authenticate)          // 公开
mux.HandleFunc("POST /api/v1/admin/login", h.Login)                  // 公开
mux.HandleFunc("POST /api/v1/admin/logout", h.Logout)                // 需会话
mux.HandleFunc("GET  /api/v1/admin/me", h.Me)
mux.HandleFunc("PUT  /api/v1/admin/password", h.ChangePassword)
mux.HandleFunc("GET  /api/v1/stats", h.Stats)
mux.HandleFunc("GET  /api/v1/projects", h.ListProjects)
mux.HandleFunc("POST /api/v1/projects", h.CreateProject)
mux.HandleFunc("GET  /api/v1/projects/{id}", h.GetProject)
mux.HandleFunc("PUT  /api/v1/projects/{id}", h.UpdateProject)
mux.HandleFunc("DELETE /api/v1/projects/{id}", h.DeleteProject)
mux.HandleFunc("GET  /api/v1/projects/{id}/keys", h.ListKeys)
mux.HandleFunc("POST /api/v1/projects/{id}/keys", h.CreateKey)
```

### 4.2 中间件链

| 中间件 | 行为 |
|--------|------|
| RequestID | 生成/透传 `X-Request-Id`，写入日志与审计 |
| AccessLog | slog 记录 method/path/status/duration/ip |
| Recover | panic → 500 JSON + 审计 `system.error`（可选） |
| LimitBody | `http.MaxBytesReader` 1MB |
| RateLimit | 按 IP+路由组限流（登录 5/min；认证 100/min 可配） |
| RequireAdmin | 会话鉴权（静态资源路径不挂） |

```jsonc
// 成功
```

## 5. 错误码设计（业务码，HTTP 状态码映射见《05》）

| 范围 | 含义 |
|------|------|
| 0 | 成功 |
| 10001-10099 | 认证业务（project_not_found / project_disabled / version_too_old / key_not_found / key_disabled / key_expired / fingerprint_mismatch / fingerprint_required / rate_limited） |
| 20001-20099 | 参数错误（invalid_parameter / invalid_json / validation_failed） |
| 20100-20199 | 登录与会话（bad_credentials / account_disabled / session_expired / unauthorized / password_too_weak） |
| 20200-20299 | 资源冲突（name_conflict / key_still_active 等） |
| 50000 | 内部错误 |

## 6. 日志规范

- 全链路 `X-Request-Id`；结构字段：`time level msg request_id method path status ip duration actor`。
- **脱敏红线**：任何日志/审计**不得**记录密钥明文、密码明文；admin 初始密码仅落 `auth.log`（D3 特殊通道）与控制台。
- 认证失败审计 `detail` 只记失败原因码，不记密钥。

## 7. 并发与事务要点

- SQLite 单写者：写事务（密钥生成+审计）用 `BeginTx` 包裹，`commit` 失败回滚。
- `last_used_at` 更新低频化：同一密钥 60s 窗口内只更新一次（内存 map + 锁，防写放大）。
- 内存限流器按 key 惰性创建，定期清理过期 key，防内存泄漏。

## 8. 优雅关闭

```
signal.NotifyContext(SIGINT, SIGTERM)
→ server.Shutdown(ctx 10s) → 等待在途请求 → 关闭 db → 写 system.shutdown 审计
```
