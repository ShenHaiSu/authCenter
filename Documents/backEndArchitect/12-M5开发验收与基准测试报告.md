## 4. 实现要点记录（对照文档）

1. **web 包源码白名单**：构建脚本清空 `BackEnd/internal/web/` 时必须保留 `.gitkeep`/`embed.go`/`embed_test.go`——embed.go 是 go:embed 声明源码，删除后 web 包无法编译（首次运行已踩坑并修复，§2.2 注释与 .gitignore 例外一致）。
2. **build.ps1 编码**：脚本含中文注释，以 UTF-8 **带 BOM** 保存，保证 Windows PowerShell 5.1（无 BOM 时按 ANSI 解码）与 pwsh 7 均可直接 `-File` 执行。
3. **版本注入**：`-ldflags "-s -w -X main.version=$Version"` 注入构建版本；产物名默认不带版本（文档允许脚本参数控制，本实现以 -Version 注入二进制内 version 为准）。
4. **部署辅助文件独立成 `deploy/` 目录**：Caddyfile.example / authcenter.service / 双平台 README 作为构建模板入库，构建期复制进 Bundle（07 §4 步骤 6）。
5. **验收方式说明**：当前环境无 docker/playwright 浏览器自动化，R5「浏览器全流程」以真实启动 + curl 全链路等效验收（覆盖前端全部 API 契约与静态资源服务），与 M4 报告口径一致。
6. **git 策略**：Bundle 产物与 BackEnd/internal/web/ 前端副本均被 .gitignore 忽略（仅保留目录骨架 .gitkeep），发布物不入库；deploy/ 与两个 build 脚本入库作为交付物。
