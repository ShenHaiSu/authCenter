# 08 测试与验收计划

> 后端架构文档 8/8 ｜ 分层测试、cgo 红线验证、手工验收矩阵、开发里程碑

## 1. 测试策略

| 层 | 工具 | 覆盖 |
|----|------|------|
| 单元测试 | `go test` | service 层纯逻辑：密码哈希、密钥生成、认证校验链、token 签发、版本比较 |
| 集成测试 | `net/http/httptest` + 临时 SQLite（`:memory:` 或临时文件） | 启动流程、admin 初始化幂等、全 API、审计写入、限流 |
| 交叉编译验证 | 构建脚本 + `go vet` | cgo 红线、双平台产物 |
| 手工验收 | 验收矩阵（§4） | 对照需求 R1-R5 与决策 D1-D4 |
| 安全评审 | 代码评审 + 检查清单（《06》§11） | 脱敏、鉴权、限流 |

## 2. 单元测试清单

| 模块 | 用例 |
|------|------|
| config | 默认值、env 覆盖、非法参数报错 |
| database | 迁移幂等（重复启动不报错）、PRAGMA 生效 |
| service/auth | 校验链每一环的成功/失败分支（§04 3.2 的 12 步）；未绑定指纹通过；require_fingerprint 生效 |
| service/apikey | 生成长度/字符集/熵；轮换后新旧密钥行为；过期判定（边界：恰好在 expires_at 时刻） |
| service/token | 签发-校验往返；过期拒绝；篡改拒绝；secret 覆盖 |
| service/admin | argon2id 哈希-校验往返；改密后旧会话失效 |
| 指纹 | 格式校验、精确匹配、大小写敏感 |

## 3. 集成测试清单（httptest）

| 场景 | 断言 |
|------|------|
| 启动初始化 | 无 admin 时创建；再次启动不重建（密码不变）；auth.log 落盘一次 |
| 登录流程 | 正确密码 → 200 + cookie；错误密码 → 401/20101 + 审计 login_failed；连续失败锁定 |
| 会话 | 无 cookie 访问管理 API → 401/20103；登出后 cookie 失效 |
| 项目管理 | CRUD 全链路；名称冲突 409；删除项目级联删密钥 |
| 密钥管理 | 生成返回明文一次；列表不含明文；过期时间修改生效；禁用后认证返回 key_disabled |
| 认证 API | 成功/项目不存在/项目停用/密钥不存在/密钥停用/已过期/指纹不匹配/限流 各分支；issue_token=true 返回可用 JWT |
| 审计 | 每个动作产生对应事件；分页与筛选正确 |
| 静态资源 | GET / 返回登录页；GET /login.html 200 |

## 4. 手工验收矩阵（对照需求）

| 需求 | 验收操作 | 预期 |
|------|----------|------|
| R1 纯 Go 禁 cgo | 双平台交叉编译；`go list -deps` 无 cgo | 构建成功，产物可运行 |
| R2 127.0.0.1:53779 HTTP | `netstat -ano` 查看监听；curl 本机 | 仅监听 127.0.0.1:53779；无 TLS |
| R3 admin 自动生成 | 首次启动观察控制台与 auth.log；重启第二次 | 首次生成 30 位随机密码并打印/落盘；重启不再生成 |
| R4 对外认证 | curl 携带项目名/版本/指纹/密钥 | 成功返回 authenticated=true；错误场景返回对应业务码 |
| R5 前端管理 | 浏览器走完登录→建项目→生成密钥→设过期/备注→查审计 | 全部可用 |
| C6 Bundle | 运行 build.ps1/build.sh | 两平台目录均含后端二进制 + 前端副本 |
| D1 可选令牌 | 认证时 issue_token=true | 返回 JWT，可用本地 secret 校验 |
| D2 完整审计 | 界面查询各类事件 | 事件齐全、可筛选分页 |
| D3 密码交付 | 首次启动日志 | 控制台 + auth.log 各一次 |
| D4 多密钥 | 同项目建多密钥，一禁一启 | 仅启用的可认证 |

## 5. cgo 红线验证（CI/发布前必跑）

```powershell
# 1. 确认无 cgo 依赖
go list -deps ./... | Select-String -Pattern 'C\.'  # 应无输出（除标准库 safe 路径）
CGO_ENABLED=0 go build ./...                         # 必须成功

# 2. 双平台编译
$env:CGO_ENABLED="0"; $env:GOOS="windows"; go build ./...
$env:CGO_ENABLED="0"; $env:GOOS="linux";   go build ./...

# 3. 静态检查
go vet ./...
gofmt -l .   # 应无输出
```
