## 4. 实现要点记录（对照文档）

1. **前端单一来源**：`FrontEnd/` 为唯一源；发布期由 build 脚本复制进 `BackEnd/internal/web/` 后 go:embed（07 §2.2）。`.gitignore` 增加 embed.go/embed_test.go 例外——web 包源码必须入库，前端副本仍忽略。
2. **根路径改造**：`/` 由占位 HTML 替换为 `http.FileServer`；拦截 `/xxx/` 目录请求（禁目录列表，06 §11）与未注册 `/api/` 路径（保持 JSON 404 + request_id，05 §1）。
3. **WebFS 双通道**：`RouterDeps.WebFS` 为 nil 时回退内嵌；main 按 `-web-dir` 注入 `os.DirFS`（开发模式，07 §2.3）。测试统一注入 FrontEnd 源目录 FS（Getwd 向上查找，兼容 go test 不同工作目录）。
4. **stats 落地**：05 §4.5 原为 P2 占位，因前端仪表盘（02 §3）依赖而提前实现：store 4 个统计方法（含"7 天内到期=不包含已过期"边界、今日=UTC 当日 0 点起）+ StatsService + handler，均需会话。
5. **前端安全约束**：所有动态渲染经 escapeHtml（XSS）；密钥明文仅存模态框 DOM，关闭/Esc/遮罩点击即清空；fetch 统一 credentials same-origin + 401 跳转。
6. **轮换语义展示**：旧密钥宽限期体现在 expires_at（后端收紧），前端以"已过期/N 天后"相对提示 + 轮换确认框文案，符合"界面仅提示"（02 §5）。
